# 计算与数据边界

2026-10-17补充：本文的五维完整性/债券不支持说明针对旧V2。新增[分类型研究参考评分](research-scoring.md)独立入口允许部分数据出分，并支持债券等六种研究类型；使用显式覆盖率、缺失范围和证据日期，不恢复旧50分回退。两种分数不可混写或混合排名，新参考分不生成仓位。

本轮修复针对V2证据不足时的错误默认行为，不代表完整投资策略已经验证。

## 已修改的行为

- 五维评分保留真实0分；缺失任一维度抛出含缺失字段的ValueError，调用方不能把缺失当中性。无评分时单基金JSON的scores为null，行动为不可评价，目标仓位和定投金额不生成。
- 暂无专用模型的债券、偏债、货币、FOF、目标日期/目标风险及未知类型，不回退到股票指数策略。已有指数和主动股票/混合分类保留。
- 不根据一年收益/同类排名构造估值或PE百分位；没有真实估值的主动基金可能无法给出综合评分，这是当前有意限制。后续可另建无需PE的主动策略并验证，不做隐式补分。
- 风险模块缺基准时Alpha、Beta、IR为未知。可显式传入日期完全一致的benchmark_history；币种、复权及合同基准身份仍须调用方核实。V2当前没有自动接入合同基准，因此相对基准指标默认缺失。
- Beta协方差与方差统一采用样本口径ddof=1；IR跟踪误差用样本标准差。基准无波动时Beta不可定义，不返回假设1。
- 下行偏差使用全样本 `sqrt(mean(min(r,0)^2))*sqrt(252)`，MAR=0。全正收益时偏差为0，Sortino不可定义，不添加人为epsilon。当前Sortino分子仍是相对年化无风险假设的收益，报告/比较时必须注明该约定。
- 真正为0的波动率、Alpha等不再序列化成null。非法非正/非有限净值不参与风险计算。
- V1技术模块N期收益使用N+1个观察点，明确为观察期数，不冒充自然日区间。
- 组合入口不再把异常或缺失评分降级为50分/持有/中风险，而是报错停止；吸引力分数不再映射产品风险等级，风险等级显示待核实。

## 仍需后续工程处理

1. 净值来源尚未统一为可靠分红再投资总回报序列；不能保证分红除息、拆分与不规则披露不会影响当前风险值。
2. 年化仍假定日频252期，无风险利率仍为2.5%的模型常量，非实时国债收益率；Calmar仍采用算术平均年化，尚未切换实际日期CAGR。不得把它们视作统一标准的精确跨基金比较。
3. 当前组合权重、部分风险统计和目标金额仍以成本为依据，未升级为同日市值权重与缺失覆盖率；不能用于准确风险敞口或下单金额。
4. 资金/情绪维度仍复用净值和价格，不是独立真实资金流或舆情证据。报告已标为启发式，尚未验证权重的预测能力。
5. V1旧入口的精确净值点位、推荐器、独立SIPAdvisor和RebalanceAdvisor仍需专项审查。当前V2入口增加的门槛不代表所有直接调用路径已重构。
6. 还没有真实持仓穿透、费用与锁定期下的样本外策略验证，也不保证15%或其他回撤目标。历史绩效、本人投资体验与未来风险分别报告。

## 使用与兼容性

调用calculate_scores时必须显式提供全部五维值；已明确评定为50分可以传50，缺失不得传50充数。策略不支持与数据缺失均可继续展示已取得的事实，但不能自动产生买卖意见。

组合入口当前采用遇到不可评分即停止的保守行为，不会自动生成跳过异常基金的完整配置图。未来若支持部分报告，需要明确显示失败条目和市值覆盖率后才能汇总。
