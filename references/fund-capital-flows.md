# 基金研究的资金方向观察

用户需要观察各方向资金、主力交易或国家队动向时，运行本模块作为基金筛选的辅助。先读报告的截至日、样本数和覆盖率；不得把“接口已实现”表述成“全部数据已取得”。

## 三个维度

- **ETF净申赎估算**：逐只ETF的当日份额差乘同日单位净值，再汇总方向。份额来自沪深交易所，净值来自东方财富公开历史净值。估算可包含实物申赎，不等于现金流水。不能用规模差额替代，也不能以汇总份额乘一只代表ETF净值。
- **ETF主力交易**：东方财富对ETF二级市场大单/超大单的资金分类统计；不识别真实机构身份，也不代表成分股全行业主力流向。与一级市场申赎分开呈现，不合并成一项“资金流”。
- **国家队观察**：机构公告、实名持仓变动及带日期的历史线索；相关ETF申赎只是产品观察。未取得每日精确成交或当前完整持仓时保留未知，不生成国家队买入概率。

国家队历史证据见 [实名持仓及数量下界](../assets/capital-flow-national-evidence.json)：四只ETF的2025年报与2026中报原文、PDF页码、公告日和单位。当前实名份额缺失时，可在确认没有拆分后，用全基金总份额作持仓上界，推算历史持仓减少的保守下界；只逐产品报告“亿份”，不能称为国家队资金流出金额或当前卖出。该证据不会自动刷新；有新原文时再更新，并核来源公布日不得晚于研究截止日。

方向样本见 [配置](../assets/capital-flow-universe.json)。默认46个方向、49只ETF，是代表样本而非完整市场。每只代码只归入一组；不同方向的底层股票仍可能重叠。名称和样本组成在报告中可查，不把代表样本称为全行业资金。

## 运行

从技能目录执行，日期采用用户所在时区的研究截止日；报告产物与缓存用用户指定的本地Private路径。

```text
python scripts/capital_flow_data.py --as-of YYYY-MM-DD --cache-dir <绝对路径/Private/Capital_Flows/raw> --output <绝对路径/Private/Capital_Flows/快照.json>
python scripts/capital_flow_report.py --input <绝对路径/Private/Capital_Flows/快照.json> --output <绝对路径/Private/Capital_Flows/资金方向观察.html>
```

第一步只采集公开代码、日期与行情，不读取或发送个人持仓。第二步离线生成一份不依赖外部图表库的HTML，内嵌数据、方向排行、1/5/20日切换、热图、逐项趋势、样本组成、国家队历史证据与来源审计。用户可以直接打开HTML，也可导出内嵌JSON。

重建已有数据时在第一步加 `--offline`，不联网。原文按代码和请求日期缓存；未知与真实0分开，单个主机失败后本轮暂停。不要不断重试失败主机或把已失败字段补成0。底层接口为公开网页接口，结构或可访问性可能变化；失败时保留缺口并报告。当前无需第三方Python包，不为普通采集安装整套AkShare。

## 解释与验收

1. 先看统一截至日与样本覆盖率。1/5/20日窗口来自沪深300ETF实际净值日，必须取得完整窗口与全部组内样本；缺失不缩短窗口。海外净值滞后也不冒用其他日期净值。
2. 金额为人民币亿元。资金强度＝窗口净额/期初样本净资产，并非平台的净流入占成交额比；超过100%不是数学错误。数据源日频窗口用于研究，不声称识别全部交易日修订。
3. 分红/折算事件字段或疑似份额折算会停用申赎估算，待核公告。规则未命中不能证明完全没有事件；样本突变仍应查原文。
4. 5日和20日均流入可列为进一步研究方向；单日异动、两窗口分歧或两渠道分歧需要说明。不自动变成买卖或加仓建议，不并入 `public-core-v2.0` 基础分。
5. 下一步研究准确指数及成分、估值、费率、跟踪偏离、流动性与个人组合重复暴露；不能凭流入金额最大选基金，也不宣称回测验证有效。
6. 国家队事件日期、公告日期、证据类型分别标注。历史相关产品池不代表当前完整持仓；后续加入新报告须保留原文、份额单位与证据位置，不能用市值增幅推增持。

离线核验：`python -m unittest tests.test_capital_flow -v`；或纳入原有pytest检查。测试验证计算和缺失行为，不验证策略收益。

参考项目：[digger-yu/etf](https://github.com/digger-yu/etf)。借鉴方向比较与时间热图；本模块独立实现，不复用其截至2025-07-08的历史数据或白银LOF估算份额。
