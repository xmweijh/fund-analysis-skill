# 基金数据源与补源规则

## 当前实际接入

| 来源 | 用途 | 主要限制 |
| --- | --- | --- |
| 蛋卷/雪球公开产品缓存 | 基础资料、阶段收益/回撤、经理团队、资产概览 | 多个接口的资产比例可能使用不同分母；QDII的股票列表可能仅含境内部分 |
| 天天基金公开费率页 `jjfl` | 管理费、托管费、销售服务费三项名义年度费率 | 完整表列示三项时合计三项；A类/场内ETF仅列两项时保留列示项小计和口径，未列销售服务费不擅填0；不能回填历史费率 |
| 天天基金资产配置页 `zcpz` | 明确标为“股票占净比”的报告期配置 | `---`不是零；不使用资产配置图上的不明分母 |
| 天天基金定期报告索引 `f10/JJGG` | 按基金代码取得管理人中报/年报原文 | 只选研究日期以前已公布的完整报告，不选摘要；接口可用性需实际检查 |
| 基金管理人公开定期报告（东方财富PDF镜像） | 同期总资产/净资产、实际股票比例、完整债券品种中的转债/交换债、完整前十权益集中度 | 核对份额代码、报告截止日和公告日；解析失败留空，不从前五债券推断零 |

原始HTML/PDF、公告索引、取得时间、字段证据、报告页码/摘录和失败状态均保存在指定缓存目录。公开产品数据与本人持仓关联后属于私密研究资料，推荐统一使用Private或已忽略的reports目录。

## 采集与离线接入

从技能根目录运行；公开采集命令仅接收六位产品代码，不接收账户或持仓金额：

```bash
python scripts/public_data_sources.py --codes <六位代码> <六位代码> --as-of <YYYY-MM-DD> --cache-dir <私密缓存目录>
```

可选`--proxy <HTTP代理地址>`，不内置个人电脑代理；`--refresh`刷新。网络请求有超时与最多三次重试；同分析日期复用缓存。刷新失败保留旧日期证据及失败状态；过期证据仍不能参与评分。需安装`pypdf`读取公开报告，其余采集和离线合并只使用标准库。费率与资产页面不依赖pysnowball。

```bash
python scripts/research_report.py --input <证据JSON> --public-data-dir <原蛋卷缓存> --supplemental-data-dir <补源缓存> --output-dir <私密输出目录>
python scripts/operation_report.py --input <操作研究JSON> --supplemental-data-dir <补源缓存> --output <私密报告.html>
```

报告生成不联网。操作报告仍只生成一个成品HTML，包含来源审计记录。网络补源和本地金额关联分开进行。研究日期与持仓记录日期需各自说明，刷新产品资料不代表刷新了本人市值。

## 来源优先级与口径

- 有效人工证据优先。来源冲突保留候选与旧证据，不静默覆盖。
- 同一报告日期，管理人资产负债表/完整投资明细可以纠正蛋卷转载值，并保留旧值与来源。抓取更晚不等于数据有效日更晚。
- 总资产/净资产直接使用同一份报告对应的金额，不把债券仓位或总资产图当杠杆。
- 只有完整债券分类表才可提取实际转债/交换债比例。明确的整行`- -`可表示该品种未持有；缺行、重仓列表无转债均不能表示零。
- 前十股票集中度取完整股票/权益明细前十公允价值之和除以同报告股票投资金额，并与每行占净值百分比复核。ETF联接和基金投资需穿透，不能用直持少量股票代替。
- 有来源不等于独立核验；新字段默认`verified=false`，不会因增加数据源就自动变为独立核验覆盖。

## 扩展研究字段（不再作为默认必填评分）

| 缺口 | 原因与所需来源 |
| --- | --- |
| 低于AA+及未评级信用债占净值 | 部分中报只列AAA/AAA以下，不能区分AA+与更低评级；未评级国债/政策债须排除，需要完整分类或逐券核验 |
| 修正久期 | 很多中报仅披露期限分布/利率敏感性；不能直接当实际修正久期，需要管理人明确披露或匹配口径的专业数据 |
| 三年合同基准超额总回报 | 平台`performance_value`可供研究，但合同历史变更、币种和基金分红总回报口径须核实；`than_value`展示指数不能代替合同基准；成立不足三年不能补造 |
| 日频跟踪误差 | 需要准确标的总回报与基金日频分红复权序列，同日同币种对齐；抽样走势不满足 |
| 五年以上准确标的估值百分位 | 需要确认指数代码、PE/PB等估值口径与完整历史；阶段涨跌和第三方评分不替代 |
| ETF联接穿透 | 需要准确目标ETF及同报告日完整成分/股票资产分母 |

覆盖率是模型所需证据的权重覆盖，不是产品数量覆盖或数据请求成功率。同一版本不得为提高覆盖率而临时缩小分母、填默认值或把不同指标改名代入。默认基础模型调整须升级版本并说明覆盖范围，不与旧深度模型的覆盖率直接比较。


## 可获取渠道与当前支持状态（核查：2026-10-18）

| 字段 | 可以从哪里获取 | 当前技能支持 | 默认处理 |
| --- | --- | --- | --- |
| 基础回撤/现任团队 | 蛋卷明确区间业绩、经理任职记录；ETF资料可回退天天基金档案与有完整日期的净值接口 | 自动采集及日期/团队校验；未满一年不造全年回撤 | 按对应类型基础模型使用 |
| AA+以下信用比例 | 管理人中报评级表；完整信用债持仓及匹配债项评级 | 原文采集已实现；精细评级重建未实现，AAA以下不能直接换名 | 移出默认评分；人工核实后可另列 |
| 组合修正久期 | 管理人明确披露；或完整组合、匹配日期逐券久期及现金/杠杆/衍生品处理 | 不自动估算组合久期；公开单券数据不等于完整组合数据 | 移出默认评分；明确披露/有授权证据才使用 |
| 三年合同基准超额 | 管理人业绩比较表；核实历史变更的基准和基金分红再投资序列 | 原始业绩展示有支持；同币种、分段三年计算尚未自动接入 | 移出默认评分；成立不足三年属于区间不适用 |
| 实际跟踪误差 | 管理人定期报告实际统计；或足够日频的标的与基金总回报 | 未自动提取报告统计或对齐计算；合同“控制在X%以内”只是目标，不能当实际值 | 移出默认评分；有对应区间和统计口径才展示 |
| 长期估值分位 | 中证/国证等指数发布方的匹配估值历史；可选用户已授权历史库 | 无统一五年历史采集；近期估值接口不等于长期分位数据 | 移出默认评分；精确指数/窗口有效才展示 |
| 联接穿透集中度 | 目标ETF相同披露期的完整权益及股票资产分母 | 直持完整权益解析已支持；自动联接穿透尚未实现 | 指数基础分不需要；不伪装已穿透 |

上述是渠道核查，不是对商业数据商全字段覆盖的保证。Wind/Choice等授权来源只有在用户已提供权限、核实具体字段/口径后才能用，本技能未内置其连接器，也不自动购买数据。

渠道依据：

- [中债估值公开查询](https://valuation.chinabond.com.cn/cbweb-mn/val/val_query_list?locale=zh_CN)列示单券修正久期等指标；据此不能推断已取得完整基金组合久期。
- [招商产业债2022中报](https://www.cmfchina.com/upload/20220830/202208301661823640229.pdf)示例披露AAA/AAA以下/未评级；这里引用其表格结构，不把旧报告作为当前基金证据。
- [AKShare官方指数数据文档](https://github.com/akfamily/akshare/blob/main/docs/data/index/index.md)注明中证估值接口只能返回近期数据；不能据此承诺五年分位完整。
- [证监会基金跟踪误差说明](https://www.csrc.gov.cn/shenzhen/c105614/c7521980/content.shtml)区分净值跟踪与场内价格，并列举合同控制目标；实际统计不能由合同上限替代。
- [指数发行人披露实例](https://samsungetfhk.com/zh-hans/product/2812/)提供实际跟踪偏离和误差定义，说明部分产品存在公开渠道，不代表全市场统一可取。
