# 分类型研究参考评分 v1.0

用户需要可比较的分数时，优先使用本模型。新入口不依赖旧V2的五维补齐门槛；旧五维分仍只在完整输入时使用，不能把新参考分写进旧`scores.total`冒充同一模型。

## 分数表示什么

这是偏向风险控制、成本及可验证表现的启发式研究分，非预期收益、买入吸引力、保本概率或官方评级。风险规则偏好更小的回撤、久期、杠杆和集中度，可能对策略本身就追求集中/长久期的基金给低分；低分说明不符合这套偏好，不证明基金经理无能力。单只高分不证明适合用户的期限和组合。

权重、节点和新鲜度阈值是本项目明确选择的研究参数，没有声称来自监管标准或已验证最优。参数在 `scripts/research_scoring.py` 的 `WEIGHTS`、`METRICS`、`knots_for` 内集中维护，JSON输出同时保留节点，便于版本复算。当前不生成字母评级、自动买卖或目标金额。

## 分类型权重（%）

| 类型 | 维度与权重 |
| --- | --- |
| bond 非权益债券 | 一年回撤25，费用15，信用20，修正久期15，总资产杠杆15，转债10 |
| enhanced_bond 增强债券 | 一年回撤20，费用15，信用15，久期10，杠杆10，转债10，股票10，三年基准超额10 |
| mixed_allocation 偏债/配置混合 | 一年回撤25，费用15，信用15，久期10，杠杆15，股票10，转债10 |
| active_equity 主动权益 | 一年回撤30，费用15，前十股票集中15，经理连续任职15，三年合同基准超额25 |
| index 股票指数/ETF联接 | 一年回撤20，费用20，前十集中10，跟踪误差25，真实估值历史百分位25 |
| money 货币基金 | 一年回撤20，费用20，信用30，常规到账工作日30 |

QDII采用对应主动/指数类型，附加汇率、海外交易日、限购和实际到账的未覆盖提示，不凭名称假定美国敞口。FOF、未知类型和未确认代码现金保留条目、暂不套模型。类型要以合同/产品证据明确提供，不能由名称里的“纯”“稳”自动归入非权益债券。

## 缺失数据怎样出分

维度标准分为`s_i`，原始权重为`w_i`（全模型合计100）。有效维度集合为A：

- 参考分 = `Σ(w_i × s_i) / Σw_i`，只对已有有效证据归一化；至少有一项有效数据就可给出局部参考分。
- 数据覆盖率 = `Σw_i`；这是模型权重覆盖，不是统计置信度或准确率。
- 完整权重下界 = `Σ(w_i × s_i)/100`；上界 = 下界＋缺失权重。缺失项分别为0和100时的范围，不是置信区间，也不包含模型误设或已用数据错误。
- 覆盖<50%标“局部参考”；50%至<80%标“暂定参考”；≥80%标“较完整参考”。这些是展示标签，不是有效性认证。
- 另列独立核验覆盖率；平台披露可以贡献暂定分，但未独立核验要明确说明。`verified=true`需研究者有核验依据，不能抓取成功就默认true。
- 真正0值/0分保留；未知不补50，不补0。全无证据时保留空分和0–100范围，不制造数字。
- 不同类型、不同可用维度/日期的分数不直接排名。组合显示已知市值中的可评分占比、按市值加权的证据覆盖，不将跨类型单分平均成“组合风险分”。未知市值不填0，标明分母不完整。

例如，主动权益只有费用60分（15%权重）和回撤60分（30%权重）：参考分60，覆盖45%，缺失项范围27–82。不能把这个60与全维度60当等量证据。

## 证据契约

每个指标必须有数值、数据日期、来源。无来源、非法数、未来日期或过期数据保留缺失原因，不评分。基本最大数据年龄：回撤/基准/估值45天，资产/信用/久期/集中180天，费率/任期/到账365天。历史披露通过年龄门槛不代表实时。

- `drawdown_1y_pct`：完整一年最大回撤，百分数正值，`period_days>=365`。平台统计可标未独立核验；成立不足一年不能把成立以来小回撤当完整一年。
- `annual_fee_pct`：同份额年度管理+托管+销售服务费，百分数。若只是名义费率或ETF联接豁免未处理，要在flags写清；不重复叠加目标ETF费用，不包含申赎费/交易税费，且不再从已扣费净值收益重复扣除。
- `lower_credit_pct`：低于AA+及未评级信用债占净资产，`basis=net_assets`；不把未评级国债/政策性金融债自动视为低信用。跨国家评级不能直接混用本阈值。不知道不能写0；高评级也不消除次级/TLAC/永续债风险。
- `duration_years`：修正久期，不能用剩余期限、基金持有期替代。
- `gross_assets_ratio`：总资产/净资产倍数，不能用债券占净值百分比代替。分子/分母需同一报告日期。
- `convertible_pct`、`equity_pct`：实际占净资产，`basis=net_assets`。合同上限不是实际仓位；确认禁止投资可以另带合同证据写0。仅前五债券未出现转债不足以写转债0。
- `top10_equity_pct`：完整前十股票合计/全部股票资产，`basis=equity_assets, complete=true`，避免低股票仓位混合虚获“分散高分”。ETF联接须穿透目标ETF；分母冲突未解保留标记，必要时不填。
- `manager_tenure_years`：当前团队所有成员共同连续任期（新成员到任日起），`team_complete=true`。不把产品成立时长或经理从业时长当当前任期。
- `benchmark_excess_3y_pct`：同日同币种累计总回报相减的百分点，完整三年；`benchmark_verified,dates_aligned,currency_matched,total_return`均true，`period_days>=1095`。基准更改要分段拼接，不得拿当前公式回填过去。
- `tracking_error_1y_pct`：真实日频基金与准确标的总回报差的年化标准差，单位%/年；上述四个核实标记均true，`period_days>=365, frequency=daily, observations>=200`。不能用单个累计跟踪差替代跟踪误差，不能对抽样稀疏走势年化。
- `valuation_percentile`：准确指数、匹配估值口径的历史百分位0–100，`target_verified=true, history_years>=5`。百分位低在本启发式中分高，但不自动表示价格会涨；历史窗口/估值字段/指数币种需在来源记录。
- `redemption_business_days`：产品常规到账工作日，个人锁定/额度/节假日仍另核；货币基金分数不证明能随时快速赎回。

其余证据（申赎费、本人流动性需求、转债条款、资金用途、完整行业集中、汇率等）仍需研究正文分析。评分只覆盖模型列明的因素。

## 输入及运行

无需新增第三方依赖；输入本地JSON，输出单文件HTML及可复算JSON：

```bash
python scripts/research_report.py --input <本地证据JSON> --output-dir <本地报告目录>
python scripts/research_report.py --input <本地证据JSON> --public-data-dir <公开产品缓存目录> --output-dir <本地报告目录>
python -m unittest tests.test_research_scoring -v
```

最小合成输入（非真实基金数据）：

```json
{
  "as_of": "2026-10-17",
  "funds": [{
    "code": "000000", "name": "合成主动权益示例", "profile": "active_equity",
    "market_value": null, "qdii": false,
    "metrics": {
      "annual_fee_pct": {"value": 1.4, "as_of": "2026-10-17", "source": "合成费率说明", "verified": false},
      "drawdown_1y_pct": {"value": 20, "period_days": 365, "as_of": "2026-10-17", "source": "合成完整一年样本", "verified": false}
    },
    "flags": ["合成数据，不代表真实产品"]
  }]
}
```

省略未知指标即可；实际证据输入与生成报告必须被Git忽略。补足可信数据后复算会改变点分和覆盖率，应保留模型版本、原始输入和日期。单文件HTML无需fetch、外部字体或本机服务。

`--public-data-dir`读取以基金代码命名的JSON，每个文件包含`retrieved_at`与`sources`，各来源为`{url,payload:{data:...}}`。支持`info`（现任经理名、成立日和最新净值日）、`detail`（manager_list及achievement_list中的fund_code/post_date）、`achievement`（阶段业绩）及`growth_3y`（基准说明）。适配器只使用匹配同基金代码的当前团队任职日期，当前名单不全/日期冲突则留缺口；手工证据优先，不覆盖已有指标。

输入可用`missing_explanations`按指标键注明实际缺口原因；只有该项确实未提供数据时展示，不绕过原日期/数值/分母校验。缓存适配器会区分“尚未接数据源”“需完整报告”“成立不足三年”等，避免把它们全部显示成数据不存在。

原版的阶段收益、名次、经理资料继续展示，不等于它们已全部参与新模型。新参考分的目标和权重与旧V1/V2不同，不应直接比较高低；未接入的字段、来源缺失、成立不足区间及口径不匹配需要分别解释。不得将旧版本可取得的真实资料一概称为虚假，也不能为了恢复旧分数用近似估值冒充真实估值。

监管投资者教育支持“分别检查债券信用/利率风险、指数跟踪及费用”等维度，并不支持本项目具体分数与阈值：

单元测试验证缺失归一化、0分、日期、基准身份、分母、部分组合覆盖及HTML转义；尚未做样本外收益预测或参数敏感性实证，不称为已经验证的选基策略。
