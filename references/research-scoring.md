# 公开数据基础参考 public-core-v2.0

默认模型用于常规公开数据研究，替代把专业数据全部设成必填的旧research-v1.0。它是有限维度的启发式参考，不是基金综合评级、收益预测或安全等级。默认字段减少属于模型范围调整，不能称为原模型的数据补齐。

## 固定基础权重（%）

| 类型 | 默认维度与权重 |
| --- | --- |
| bond | 一年回撤35，名义费用20，总资产/净资产25，转债20 |
| enhanced_bond / mixed_allocation | 一年回撤30，费用20，杠杆20，转债15，股票15 |
| active_equity | 一年回撤40，费用20，完整股票集中度20，现任团队共同任期20 |
| index（含联接） | 一年回撤60，费用40 |
| money | 费用40，注明销售渠道的常规到账60 |

权重是本项目设计，不是监管认可或回测最优参数。不得按每只产品获取成功的字段重新挑权重。指数基础分不衡量跟踪质量、指数估值或择时；货币基础分不衡量信用安全；债券基础分不衡量信用质量和久期；主动基础分不衡量选股和超额能力。各产品报告同时展示对应范围。

FOF、未知类型及未确认代码条目不套模型。QDII套对应产品类型，并核实币种、日历、海外持仓和到账；境内股票列表不能认定为全球完整前十。ETF联接的少量直接股票不作为已完成穿透的集中度。

## 扩展字段

信用细分、组合修正久期、三年合同基准超额、日频跟踪误差和长期指数估值分位不进入默认基础权重；指数完整集中度和货币历史回撤也仅作为扩展证据。已有且通过原证据校验时列在“已取得的扩展研究证据”，不参与基础分、不影响基础覆盖率。不生成未取得扩展项的空白评分行。

渠道与自动化状态见[字段渠道表](fund-data-sources.md)。有渠道不等于当前适配器已实现；深度结论依赖的证据未取得时，只在该结论附近明确限制，不能把删除空白行写成已完成风险核验。

## 评分与覆盖

- 有效维度按固定权重归一化；未知不填0或50，真实0保留。全无基础证据时无分数。
- 覆盖率是本版本有效基础权重之和；100%只表示这些基础维度齐全，不表示信用、利率、跟踪、估值等全面覆盖。跨版本覆盖率不能比较。
- 缺失项范围为缺失基础维度分别取0/100的上下界，不是置信区间。
- 不同类型或不同证据集不直接排名，不平均为组合风险分，不从分数生成交易指令。
- 独立核验覆盖另列。抓取成功不自动设置verified=true。

## 运行和版本

```bash
python scripts/research_report.py --input <本地证据JSON> --output-dir <本地输出目录>
python scripts/operation_report.py --input <本地研究JSON> --output <本地报告.html>
```

可加`--supplemental-data-dir`离线读补源缓存；研究报告可加`--public-data-dir`接入原蛋卷缓存。两个入口均支持`--scoring-model research-v1.0`显式复算旧模型；也可在输入JSON顶层设`scoring_model`。未指定时使用public-core-v2.0；未知版本直接报错，不静默回退。输出记录实际版本、评分范围及覆盖分母。历史个人报告不会自动覆盖。

最小示例见[合成输入](../examples/public-core-input.json)，仅供离线运行，不代表真实产品。回归用合成数据；Python标准库即可完成离线评分，公开PDF采集另需pypdf。

## 证据契约

每个指标必须有数值、数据日期、来源。无来源、非法数、未来日期或过期数据保留缺失原因，不评分。基本最大数据年龄：回撤/基准/估值45天，资产/信用/久期/集中180天，费率/任期/到账365天。历史披露通过年龄门槛不代表实时。

- `drawdown_1y_pct`：完整一年最大回撤，百分数正值，`period_days>=365`。平台统计可标未独立核验；成立不足一年不能把成立以来小回撤当完整一年。
- `annual_fee_pct`：同份额年度运作费率，百分数。三项均列示时合计管理+托管+销售服务费；完整公开表只列两项时保留列示项小计、components及fee_scope，不将未列销售服务费写成0，也不声称实际总费用。若只是名义费率或ETF联接豁免未处理，要在flags写清；不重复叠加目标ETF费用，不包含申赎费/交易税费，且不再从已扣费净值收益重复扣除。
- `lower_credit_pct`：低于AA+及未评级信用债占净资产，`basis=net_assets`；不把未评级国债/政策性金融债自动视为低信用。跨国家评级不能直接混用本阈值。不知道不能写0；高评级也不消除次级/TLAC/永续债风险。
- `duration_years`：修正久期，不能用剩余期限、基金持有期替代。
- `gross_assets_ratio`：总资产/净资产倍数，不能用债券占净值百分比代替。分子/分母需同一报告日期。
- `convertible_pct`、`equity_pct`：实际占净资产，`basis=net_assets`。合同上限不是实际仓位；确认禁止投资可以另带合同证据写0。仅前五债券未出现转债不足以写转债0。
- `top10_equity_pct`：完整前十股票合计/全部股票资产，`basis=equity_assets, complete=true`，避免低股票仓位混合虚获“分散高分”。ETF联接须穿透目标ETF；分母冲突未解保留标记，必要时不填。
- `manager_tenure_years`：当前团队所有成员共同连续任期（新成员到任日起），`team_complete=true`。不把产品成立时长或经理从业时长当当前任期。
- `benchmark_excess_3y_pct`：同日同币种累计总回报相减的百分点，完整三年；`benchmark_verified,dates_aligned,currency_matched,total_return`均true，`period_days>=1095`。基准更改要分段拼接，不得拿当前公式回填过去。
- `tracking_error_1y_pct`：真实日频基金与准确标的总回报差的年化标准差，单位%/年；上述四个核实标记均true，`period_days>=365, frequency=daily, observations>=200`。不能用单个累计跟踪差替代跟踪误差，不能对抽样稀疏走势年化。
- `valuation_percentile`：准确指数、匹配估值口径的历史百分位0–100，`target_verified=true, history_years>=5`。百分位低在本启发式中分高，但不自动表示价格会涨；历史窗口/估值字段/指数币种需在来源记录。
- `redemption_business_days`：产品常规到账工作日，个人锁定/额度/节假日仍另核；货币基金分数不证明能随时快速赎回。


货币基金基础到账证据还必须包含非空channel（具体销售渠道），普通到账和快速赎回规则分开，不能把某渠道快速赎回额度当普遍规则。当前补源适配器不自动取得个人渠道到账条件。

## 旧版兼容模型（仅显式选择）

research-v1.0保留原证据门槛及以下权重，使用LEGACY_WEIGHTS；只作历史复算，不是默认必填模板。新旧点分、缺失范围与覆盖率不能直接比较。旧报告输出无版本输入时，复算应显式补上旧版本。

## 分类型权重（%）

| 类型 | 维度与权重 |
| --- | --- |
| bond 非权益债券 | 一年回撤25，费用15，信用20，修正久期15，总资产杠杆15，转债10 |
| enhanced_bond 增强债券 | 一年回撤20，费用15，信用15，久期10，杠杆10，转债10，股票10，三年基准超额10 |
| mixed_allocation 偏债/配置混合 | 一年回撤25，费用15，信用15，久期10，杠杆15，股票10，转债10 |
| active_equity 主动权益 | 一年回撤30，费用15，前十股票集中15，经理连续任职15，三年合同基准超额25 |
| index 股票指数/ETF联接 | 一年回撤20，费用20，前十集中10，跟踪误差25，真实估值历史百分位25 |
| money 货币基金 | 一年回撤20，费用20，信用30，常规到账工作日30 |
